# Changelog / История изменений

## 0.4

- Added installation directly from Magisk Manager storage picker.
- Added automatic Russian/English installer messages and notifications.
- Added a Magisk action button for manual log export.
- Removed the proprietary WLAN binary from the distributable ZIP; the exact
  supported driver is now copied, patched and fully verified on-device.
- Added bilingual GitHub documentation.

- Добавлена установка через «Установить из хранилища» в Magisk.
- Добавлен автоматический русский/английский язык установщика и уведомлений.
- Добавлена кнопка действия Magisk для ручного экспорта журналов.
- Фирменный WLAN-драйвер исключён из ZIP: поддерживаемая версия копируется,
  изменяется и полностью проверяется непосредственно на телефоне.
- Добавлена двуязычная документация для GitHub.
